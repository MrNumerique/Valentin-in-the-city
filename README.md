# Retrouve le supermarché

Jeu de sensibilisation créé pour les **Journées Nationales d'Action contre l'Illettrisme (JNAI)**.

Le joueur part d'un point de la ville et doit trouver le supermarché. La ville ne contient aucun écrit, seulement des bâtiments et des pictogrammes. Le joueur s'oriente grâce aux lieux repères et à une voix guide, gérée par l'animateur ou l'animatrice.

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune installation n'est nécessaire et le jeu fonctionne hors ligne.

- Déplacements : flèches du clavier (ou ZQSD), ou croix tactile à l'écran.
- Menu ⚙️ (réglages animateur) :
  - numéro de ville : un même numéro donne toujours la même ville ;
  - point de départ : devant un lieu repère ou choisi sur la carte ;
  - nombre de pas maximum, avec le trajet le plus court comme repère ;
  - mode animateur, vision limitée, affichage du nom des lieux.
